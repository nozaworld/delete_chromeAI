# AIモード非表示ツール

このChrome拡張機能は、Google検索の結果ページに表示される「AIモード」や「AIによる概要」といった機能を非表示にします。AI機能が不要な方や、よりシンプルで高速な検索体験を好む方のために作られました。

### 特徴
* AIモードの非表示: 検索フィルターの「AIモード」ボタンを非表示にします。
* AI概要の非表示: 検索結果の上部に表示される「AIによる概要」セクションを非表示にします。

---

### インストール方法

以下の手順で、この拡張機能をChromeに追加できます。

1.  このプロジェクトのGitHubページにアクセスし、「Code」ボタンから「Download ZIP」を選択してファイルをダウンロードします。
2.  ダウンロードしたZIPファイルを解凍します。
3.  Chromeブラウザを開き、アドレスバーに `chrome://extensions` と入力して拡張機能ページに移動します。
4.  右上の「デベロッパーモード」をオンにします。
5.  「パッケージ化されていない拡張機能を読み込む」ボタンをクリックし、解凍したフォルダを選択します。

これでインストールは完了です。

---

### 注意事項
* Googleの検索ページの仕様変更により、本拡張機能が動作しなくなる可能性があります。その際は、このリポジトリで更新情報をご確認ください。
* 本拡張機能は、ユーザーのいかなる情報も収集しません。
